# Anochem Group

A full-stack web application built for **Anochem Group**, a cosmetics company.  
The project provides a backend system for managing products and content, alongside a frontend interface for displaying and interacting with product data.

---

## 🚀 Overview

Anochem Group is a web-based platform designed to support corporate product management and presentation.  
It demonstrates a clean separation between **backend services** and **frontend consumption**, following modern web development practices.

---

## 🧠 Backend Features

- RESTful API built with **Node.js** and **Express**
- CRUD operations for product management
- Modular project structure for scalability
- Middleware-based request handling
- MongoDB integration for persistent data storage
- Clean separation of routes, controllers, and models
- Redis for caching

---

## 🎨 Frontend Features

- Responsive user interface for displaying products
- Dynamic data fetching from backend APIs
- Clean and structured frontend codebase
- Designed to integrate seamlessly with backend services
